# v0.2.0-alpha.1 — 120 FPS and selectable resolution

This release brings the optimized 120 FPS game to GitHub, with three render
resolutions you can choose in the Video menu.

## New features

- **1080p, 1440p and 2160p (4K), all targeting 120 FPS.** Open **Video → Video
  mode**, choose a resolution and select **Apply**. A fresh configuration
  defaults to 4K; existing supported selections are respected.
- **Saved resolution choice.** Applying a mode saves it immediately, so the
  next launch restores your setting even after closing through the shell.
- **Faster 4K gameplay.** GPU depth clears, water and brush batching, command
  reuse and presentation overlap address the slow underwater and busy views.
- **Improved frame pacing.** Runtime scheduling changes resolve the observed
  60 FPS stalls in the opening and otherwise quiet scenes.
- **Safe renderer restarts.** Resolution switches reset the renderer's cached
  objects after graphics teardown, fixing the restart crash found in testing.
- **Updated [PS5 OpenGL](https://github.com/blackbearreloaded/ps5-opengl)
  integration**, with the exact frozen SDK, patched runtime sources, dependency
  sources and focused regressions available alongside the game download.

The top-left FPS overlay, responsive DualSense controls, stereo sound, local
saves and shell artwork/music remain included.

## Download and install

Download **PPSA99007.zip** and its `.sha256` file. Verify the checksum, extract
the ZIP and copy the complete `PPSA99007` folder to `/data/homebrew/`.
The verified Quake II 3.14 demo is included, with its original notices.
Back up your saved data before updating. Retail data remains separate.

**Use the extracted folder.** FFPFSC downloads remain withdrawn because the
compressed image failed to start on the tested console.

The SDK and source archives are for developers; they are not needed to play.

## Why the TV can still show 4K/120 Hz

The Video menu changes the game's render resolution. HDMI output is managed
by the console, so lower-resolution frames can be scaled into the same
4K/120 Hz signal. This is expected. Read the in-game overlay for actual FPS.

## Validation and scope

- [GitHub Actions build](https://github.com/blackbearreloaded/ps5-yamagi-quake2/actions/runs/34666849359): passed for commit `65b2a33`.
- Downloaded ZIP: checksum, all 77 files, native executable integrity,
  complete demo data and original notices verified.
- **Exact CI-built folder tested on PS5:** the normal 4K menu measured
  **119.88 FPS** across 12 steady 120-frame windows.
  Saved settings reloaded, exact-title close and runtime release succeeded,
  and services remained healthy. The console lock was released.
- `validation.json` records artifact identities and test scope;
  `SHA256SUMS` covers the release downloads. The separate manual gameplay
  observations below apply to the tested development candidate.

The owner reported 120 FPS throughout the tested areas of the optimized 4K
candidate, including the opening and underwater. An automated test completed
six resolution switches: steady 120-frame windows measured about 119.9 FPS
at 1080p and 1440p and 117–120 FPS at 2160p. These are bounded demo-level
results on one firmware-6.02 PS5, not a guarantee for every scene or console.

Host regressions cover resolution selection and persistence, renderer
restarts, lifecycle, rendering, input, audio, save paths and packaging.
The release validation receipt records the independent Actions build and
the checks performed on its downloadable ZIP.

A compatible display and console output configuration are needed for 120 Hz.
The release remains an alpha: full campaigns, expansions, multiplayer, long
sessions, suspend/resume and device-loss recovery need separate validation.
The game-specific runtime has focused checks, not a new full graphics CTS run.
